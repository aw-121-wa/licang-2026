# 底盘距离控制重构

目标：减少提速后的软件距离误差，并支持前进、横移独立实车标定。

保留 F6、四轮同步触发、75 mm 轮径、现有运动 API 和比赛动作表。距离仍为指令积分，不新增未经确认的驱动器反馈协议。

实现顺序：
1. 用真实 motion_control、motor_control、mecanum 代码，模拟 UART 发送耗时和同步生效，复现短距离、高速及轮速限幅误差。
2. 在 BSP 记录成功同步发送时刻；积分使用量化后的轮速反解与实际生效时刻。
3. 用剩余距离的制动速度包络取代固定时间结束的三阶段逻辑，限制加速度，保留 STOP、视觉截断和通信失败处理。
4. 把前进、横移距离系数集中在 robot_config.h，默认 1.0；提供独立标定方法，不猜测机械补偿值。
5. 回归方向、短段、不同速度、限幅、时钟回绕、STOP/通信/IMU 故障；执行 build.ps1 和 GCC 构建，记录真实结果。

验收：理想无打滑模型中零末速度的目标误差不大于 1 mm；积分与同步后模拟位移一致。实车精度必须重新测量，不能把模型结果作为实际精度承诺。
