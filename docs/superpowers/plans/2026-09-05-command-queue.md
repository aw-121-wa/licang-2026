# 指令通道与电机映射调整

用户要求删除影响正常收发的状态判断，并确认地址 1 右前、2 左前、3 左后、4 右后。

已实施：
- BSP 前轮地址互换，安装方向按物理左右侧保留；算法逻辑轮序不变。
- 删除接收端 Ready/Busy、舵机/转盘/仓库状态拦截，恢复 4 条 FIFO 排队能力。
- 删除舵机启动失败后的死循环以及动作失败时对全局 Ready 的锁定。
- 通过 STOP 代次验证和任务领取时清理请求，防止队列中的后续指令取消正在处理的 STOP。
- 保留运动本身的参数、IMU、UART、STOP 与完成/超时检查；用户的 USART2 115200 改动保持。

验证：主机执行真实电机协议和算法，覆盖新的物理轮序、多方向距离、发送限幅；执行真实指令提交和领取函数，覆盖异常诊断状态入队、满队列、STOP 清空以及出队竞争。

验证通过：144 组距离/方向/速度组合、16 个底盘专项场景、FIFO 接收/队列满/STOP 清空与出队竞争测试。

全套 33 个 unittest：30 通过，3 失败。两个既有 PATH/STAIR 契约失败；另一个测试仍要求 USART2 9600，与用户保留的 115200 设置不一致。
