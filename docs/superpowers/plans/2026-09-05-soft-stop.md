# 固定距离完成时的软停车

用户确认偏转发生于固定距离结束，STOP 不在本次软刹车范围。

当前已有航向 PD，但低速修正额度随平移速度归零，正常结束直接发送零速。

实施：
1. 主机记录真实 F6 同步后的速度轨迹，检查高速提前减速、低速速度跳变、零速后的航向扰动。
2. 将正常减速度从 300 降至 120 RPM/s；20 RPM 以下使用 40 RPM/s 的连续分段制动包络，预留末段制动距离。
3. 正常零末速度结束时，以 40 RPM/s 收完残余平移速度，并增加 300 ms 有限停车锁头窗口；角度修正最多 3 RPM，限制变化率，末尾渐退到零。
4. 复用现有航向 PD 与原航向基准；不在停车时重置偏角。STOP、视觉提前截断、通信/IMU 失败仍立即停车，非零末速度衔接不等待。
5. 验证距离模型、正常刹车轨迹、停车扰动、故障中断及构建；实车效果仍需在相同速度、负载、地面下复测。

验证结果：旧实现未通过减速度和零速后航向扰动测试。修改后 144 组距离模型与 21 个专项场景通过；1 m/130 RPM 模型在 701 mm 开始减速，最终积分约 1000.125 mm。简化角度模型中的 1° 停车扰动降至 0.576°，仅证明修正方向与停车窗口有效，不是实车收敛保证。

完整测试仍有 3 个既有/配置契约失败（PATH、STAIR、用户改为 115200 的 IMU）。Keil 路径缺失；GCC 构建成功，既有 PATH 注释及链接警告保留。未烧录和实车验证。
