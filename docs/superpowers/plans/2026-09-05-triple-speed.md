# 平移巡航提至三倍

以本轮读取的配置为准：普通巡航 150→450 RPM，斜行 85→255 RPM，单轮限速 150→460 RPM，预留普通巡航航向修正额度。速度编码继续为 0.1 RPM，四台 Emm 驱动 S_Vel_IS 应保持 Enable。

加速度、减速度、停车方式和专用定位/旋转速度保留；短距离受加減速包络限制，不承诺整段运动耗时缩为三分之一。PATH/CANGKU 引用普通巡航参数的步骤同步提速。

真实 C 主机测试 22 个专项场景及 252 组距离/方向/速度组合通过，包含长距离达到 450 RPM 和 660 RPM 超限请求；理想模型最大距离误差 0.454 mm。GCC 构建 0 错误、10 个既有警告，Keil 缺失。尚未烧录或验证高速实车停车。
