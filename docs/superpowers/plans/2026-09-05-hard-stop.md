# X42S 四轮硬停

用户反馈软停后除左后轮外其余轮子回滚，并确认驱动固件已换为 X42S。

实现复用已有 BSP StopAll 和运动控制速度接口：删除停车后的 300 ms PD 修正，将零车体速度统一转换为单帧广播立即停止；保留行驶减速、四轴 F6 同步和非零末速度连续衔接。停车不失能，不发送 FF，避免停车流程释放旧的部分速度缓存。发送失败重试一次并报告错误；积分在成功发送时切换为零速度。

协议交叉参考：[厂家 X 系列通用协议](https://blog.csdn.net/zhangdatou666/article/details/135709033) 的广播地址、立即停止和同步控制说明。代码使用已有 FE/98/6B 协议族；未增加 X42S 多机状态回包解析，也未修改驱动 EEPROM。用户确认新型号，但具体驱动版本和实物执行仍须验证。

验证：真实 C 主机运行覆盖 19 个专项场景与 144 组距离/方向/速度；当前用户两轴 0.125 系数下，对补偿后目标的最大理想模型误差 0.485 mm。全套 unittest 33 项，30 通过，3 项旧契约失败（PATH 步数、IMU 波特率、STAIR 超时）。Keil 缺失，GCC 0 错误、10 个既有警告。

未烧录、未实车运行。不能保证断线、驱动异常或保持参数不一致时的物理同步停车；当前只验证四轮使用同一停止帧，且停止流程不再产生后续角度修正。
